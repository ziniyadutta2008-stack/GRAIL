# Demonstration source documents

This folder holds the original synthetic portfolio documents locally. The PDF and DOCX files are **git-ignored**. The canonical repository is public, and the owner has not yet confirmed that the originals may be published.

- The runtime never reads these files.
- The normalized seed data under `seed/` is the version-controlled source of truth. Every seed record carries a `provenance` reference back to its file and page or section.
- `docs/reference/demonstration-map.md` maps each document to modules, seed records, screens and workflows.
- `Microsoft-Responsible-AI-Standard-v2-General-Requirements-3.pdf` is a third-party publication. Keep it private permanently and cite it by public URL only.

All of the material is synthetic demonstration evidence. It does not show that any product or organization is certified or compliant.
